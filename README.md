# IT Asset Management System | ServiceNow


## 📌 Overview

The **IT Asset Management System** is a ServiceNow application developed to automate the complete lifecycle of IT assets within an organization. The application enables employees to request assets, allows administrators to allocate and manage assets, and provides real-time tracking through reports and dashboards.

The project demonstrates core ServiceNow development concepts including custom tables, forms, Business Rules, Client Scripts, UI Policies, Flow Designer, and reporting.

---

# 🚀 Features

### Asset Management
- Create, update and manage IT assets
- Track asset lifecycle
- Asset availability status
- Asset categorization

### Employee Management
- Employee information management
- Asset allocation history
  

### Asset Request
- Submit asset requests
- Request tracking
- Request approval process

### Approval Workflow
- Manager Approval
- Asset Allocation
- Status Updates

### Automation
- Business Rules
- Client Scripts
- UI Policies
- Flow Designer

### Reporting
- Asset Inventory Report
- Available Assets
- Allocated Assets
- Asset Category Report

### Dashboard
- Asset Statistics
- Allocation Summary
- Asset Status Overview
